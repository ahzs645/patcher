## How it was reconstructed

- The outer cream and dark green silhouettes are clean joined shapes, so the oval and bottom tab have no intervening seam.
- The oval rules and central opening use a small number of smooth cubic curves matched to the reference proportions. They are intentionally fuller than standard ellipses.
- The eight-tier fir tree uses hand-authored dark and green silhouettes, with tapered branch cutbacks. The trunk joins the foreground continuously. The overall tree geometry is regularized to be largely bilateral.
- Mountains, foothills and the two horizontal water lines are independently editable paths.
- The five PARKS capitals were drawn as geometric letterforms with true open counters.
- The ring lettering was rebuilt using clean outlined type designs with separately fitted scale, rotation and placement. R and M were redrawn to match the reference's distinguishing shapes. The other letterforms use outlines from Nimbus Sans Bold, Nimbus Sans Narrow Bold and DejaVu Sans Bold, choosing one design consistently for each distinct letter. This does not identify the original historical font.
- No automatic bitmap tracing was used. Surface texture, edge noise, lighting and tiny raster irregularities were replaced with smooth geometry and flat colour.

## Editing and scaling

The SVG uses the original image coordinate system: viewBox 0 0 1122 1402. Open it in an SVG-capable vector editor, select the named layer or path, and edit its fill, stroke or geometry. All lettering is converted to outlines; it remains editable as vector shapes, but is not live typeset text. No font installation is needed to display it.

Resize with the aspect ratio locked and scale strokes with the artwork. The PDF preserves vector paths and can be scaled for printing. Physical production size was not specified.

The isolated central emblem is supplied separately for reuse. It shares the same geometry as the master.

## Verification and limits

The reconstruction was rendered and compared with the reference in its original coordinate system. The comparison's magenta overlay shows boundaries from the rendered vector; no translation, rotation, scaling or local warp was used to register the overlay before it was placed on the comparison sheet.

Structural checks confirm that the master has no raster image elements or font dependencies, and that the PDF contains vector artwork without image objects. This is a new reconstruction based on the supplied reference, not recovered official production artwork. Small lettering and optical differences remain possible.
